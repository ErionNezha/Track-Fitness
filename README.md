# Track Fitness (Java/JavaFX)

Aplikacion fitness në Java (JavaFX + MySQL) — regjistrim anëtarësh, gjurmim stërvitjesh dhe panele statistikash.

`Java` `JavaFX` `MySQL`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/Track-Fitness/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.

## ▶️ Ekzekutimi origjinal
Hap `src/` në IntelliJ me JavaFX SDK; konfiguron MySQL sipas Databasecon.java.
